# Tadabbur v2 design direction

The Stitch palette is retained as the inspiration, but the interface is redesigned as a light, quiet reading/study environment.

Palette:
- Parchment background: #F5F0E5
- Warm white surfaces: #FFFDF8
- Deep ink-green: #233B34
- Accent gold: #B58D45
- Soft sage: #8BA092
- Muted text: #68736F
- Hairline border: #DDD7CA

Typography:
- UI: Manrope
- Editorial headings: Newsreader
- Quran Arabic: Amiri

UX principles:
- One primary action per screen.
- Short explanatory copy.
- No crowded dashboards.
- Large readable Arabic with generous line-height.
- Quran Arabic, translation and AI-generated explanation remain separate.
- No gamification, streaks, user accounts, permanent progress or Tafsir UI.
- Makkah imagery is used sparingly as a calm visual anchor on the home page.
